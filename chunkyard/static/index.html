How this works

A retrieval system can't read a whole document every time someone asks a question. It cuts the document into passages first, then fetches only the few most likely to hold the answer and shows those to the model. How you cut the document quietly decides what the system is capable of answering. Chunkyard cuts the same document three ways so you can watch that happen.

3 · Ask
